# ParkSmart – Parking Management System

## 📌 Project Overview

**ParkSmart** is a database-driven **Parking Management System** developed as part of our **Database Management Systems (DBMS)** project. The system is designed to simplify and organize parking operations by managing vehicle records, parking slots, parking duration, and parking fees through a centralized database.

The project demonstrates how database concepts can be applied to a practical, real-world problem. It provides an organized interface for managing parking information while reducing manual record-keeping and improving the efficiency of parking management.

## 🎯 Objectives

The main objectives of ParkSmart are to:

* Manage vehicle and customer information efficiently
* Keep track of available and occupied parking slots
* Record vehicle entry and exit information
* Calculate parking fees based on parking duration
* Store and retrieve parking records using a relational database
* Reduce manual paperwork and record-keeping
* Provide a simple and user-friendly parking management experience

## ⚙️ Key Features

* 🚗 **Vehicle Management** – Store and manage vehicle information
* 🅿️ **Parking Slot Management** – Monitor parking slot availability
* 🕒 **Entry & Exit Tracking** – Record vehicle arrival and departure
* 💰 **Parking Fee Calculation** – Calculate fees based on parking duration
* 🗄️ **Database Management** – Store and retrieve records using MySQL
* 🔄 **CRUD Operations** – Create, read, update, and delete relevant records
* 📊 **Organized Records** – Maintain structured parking information

## 🛠️ Technologies Used

* **Java** – Application/backend logic
* **MySQL** – Database management
* **HTML & CSS** – User interface
* **SQL** – Database queries and operations

## 🗃️ Database Concepts Demonstrated

This project applies several important DBMS concepts, including:

* Entity Relationship (ER) Modeling
* Relational Database Design
* Primary & Foreign Keys
* Relationships between entities
* Normalization
* SQL Queries
* CRUD Operations
* Data Integrity
* Database Connectivity

## 🚀 Purpose of the Project

ParkSmart was developed primarily as an academic project to demonstrate our understanding of **database design, SQL, application-database connectivity, and practical implementation of DBMS concepts**.

Through this project, we gained hands-on experience in designing a database-based application and working collaboratively to transform theoretical DBMS concepts into a functional system.
